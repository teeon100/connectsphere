# ConnectSphere

A full stack social media platform with real-time direct messaging, post feeds, profile management, and role-based access control.

Built with **Angular** on the frontend and **Java Spring Boot** on the backend, backed by a normalized **PostgreSQL** database.

---

## Features

- **Real-Time Messaging** — Live direct messaging via WebSocket, no page refresh required
- **User Authentication** — JWT-based login with bcrypt password hashing
- **Post Feeds** — Create, read, update, and delete posts with a dynamic friend/follower feed
- **Profile Management** — Full user profile CRUD and relationship management (follow/unfollow)
- **Role-Based Access Control** — Admin and standard user roles enforced at the API level
- **Optimized Frontend** — Lazy-loaded Angular modules and OnPush change detection reduced initial bundle size by 35%
